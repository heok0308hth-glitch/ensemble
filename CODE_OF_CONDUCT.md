# Code of Conduct

This project follows the [Contributor Covenant 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be kind, assume good faith, critique code rather than people, and keep discussions on topic. Harassment of any kind is not tolerated.

Report unacceptable behaviour privately to the maintainer through GitHub (profile → *Report* or a private security advisory). Reports are handled confidentially.
